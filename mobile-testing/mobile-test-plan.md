# Mobile Application Testing

## Devices

- iPhone
- Android device

## Testing Areas

### Functional Testing

- Login
- Registration
- Navigation
- Search
- Forms
- Notifications
- Logout

### Compatibility Testing

Test across:

- Different devices
- Different screen sizes
- Different OS versions
- Wi-Fi
- Mobile data
- Poor network conditions

### Usability Testing

- Text readability
- Button accessibility
- Screen orientation
- Keyboard behavior
- Touch interactions

### Negative Testing

- Offline mode
- Network interruption
- Invalid inputs
- Session expiration
- App background/foreground behavior
